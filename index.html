Tentang Saya

Halo, perkenalkan nama saya M. Fadel Kusmen Heri dari kelas X.U-4. Saya adalah siswa yang sedang mempelajari dasar-dasar pembuatan website, terutama penggunaan HTML untuk menyusun struktur halaman dan CSS untuk mengatur warna, ukuran, jarak, serta tampilan desain website. Saya ingin terus belajar agar dapat membuat website yang lebih rapi, menarik, dan mudah digunakan oleh pengunjung.

Dalam PSTS Ganjil mata pelajaran Web Design ini, target saya adalah mendapatkan nilai yang baik dengan mengerjakan setiap tahap secara teliti dan berurutan. Saya juga ingin memahami penggunaan Git dan GitHub, mulai dari membuat commit, membuat branch, menggabungkan branch, hingga mempublikasikan hasil website menggunakan GitHub Pages. Dengan tugas ini, saya berharap kemampuan web design saya dapat berkembang dan menjadi bekal untuk membuat proyek website berikutnya.
